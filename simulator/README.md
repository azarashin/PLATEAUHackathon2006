# Unity シミュレーター

PLATEAU の3D都市モデルから環境コストを生成する Unity プロジェクトです。

## 固定バージョン

- Unity 6000.5.9f1（Unity 6.5）
- PLATEAU SDK for Unity 4.3.0（Issue #4 で導入）

## 開き方

Unity Hub の「Add project from disk」でこの `simulator/` ディレクトリを指定します。

現在は Issue #1 の最小プロジェクトです。Unity 6000.5.9f1 での Editor 起動と ProjectSettings の生成は確認済みです。Library、Temp、Logs、UserSettings 等はコミットしないでください。

PLATEAU SDK 導入、都市モデル読込、自由視点、ビルド検証は Issue #4 で行います。
