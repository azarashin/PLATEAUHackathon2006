# Issue #12 受け入れ確認

地域・現在地・起終点・日時指定を Viewer の実機能へ接続する Issue #12 の受け入れ確認記録です。

## 確認済みの操作

- 京都市、舞鶴市、藤沢市、さいたま市、市ヶ谷周辺を選択し、選択地域の中心へ地図が移動する。
- 地域を切り替えると、既存の起終点、道路表示、経路、KPI を初期化する。
- 地図クリックで出発地・目的地を指定し、経路 API が道路グラフへスナップした3経路を返す。
- 日時選択肢は、選択地域で事前計算済みの時刻だけを表示する。
- HTTPS または localhost 上で、利用者操作による GPS 取得、現在位置・精度表示、地域内外の案内を確認した。
- GPS 座標は表示にのみ使用し、経路 API へ送信しない。

京都市、舞鶴市、藤沢市、さいたま市は経路用の解析バンドルが未配備のため、`not-precomputed` を表示して検索を抑止する。これは結果なしを別地域のデータで補わないための正常な MVP 動作である。市ヶ谷周辺は事前計算済み時刻と経路検索を提供する。

## 自動検証

2026-08-26 に次を実行し、すべて成功した。

```powershell
Set-Location viewer
npm test
npm run build

Set-Location ../server
npm test
```

- Viewer: データ契約、地域・GPS ドメイン、起終点・経路表示、道路辺表示のテストに成功し、型検査と本番ビルドに成功。
- Route server: HTTP API、道路スナップ、3経路、欠損データ、エラー応答を含む11テストに成功。
