# Runtime UI デザイン方針

Runtime Player は都市計画担当者が長時間の解析・比較作業に使う画面である。高彩度の面を常用せず、読み取りやすさと状態の意味を優先する。

## 基本配色

| 用途 | 色の役割 |
| --- | --- |
| 背景・パネル・入力面 | 白〜ごく薄いグレーを基本とする。本文は濃い青灰色で表示する。 |
| 情報・見出し・選択状態 | 青を使う。地図や解析条件など中立的な操作を示す。 |
| 実行・保存・通常の肯定操作 | 青緑〜緑を使う。実行可能・正常完了・保存済みを示す。 |
| 注意・要確認 | オレンジ系を限定して使う。欠測、再解析要求、確認が必要な状態に限る。 |
| エラー・危険操作 | 赤系を限定して使う。失敗、無効状態、削除などの危険信号に限る。 |

## 実装ルール

- ボタン文字と背景、入力文字と入力背景には十分な明度差を設ける。
- 通常画面でオレンジ・赤を装飾目的に使用しない。
- Full HD を基準に、本文は 11 px、見出しは 14〜15 px とし、状態文を含めてパネル内に収める。
- 縦方向に収まらない編集機能は `ScrollView` に収め、状態文と操作部が次のパネルへ重ならない余白を確保する。
