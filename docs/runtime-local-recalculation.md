# Runtime施策の局所再計算・取消・証跡

## 操作

Runtime Playerで施策を追加・移動・寸法変更・削除した後、**日陰解析**パネルから対象時刻または全時刻（0:00〜23:00）の解析を実行する。

- 初回の解析、シナリオの新規作成・複製・読込・既存JSON取込後は、全道路を再計算する。
- 同じ時刻の完了済み結果があり、施策を追加・移動・寸法変更・削除した場合は、変更前後の施策形状から影響候補の道路辺を抽出して局所再計算する。
- 実行中は処理済み道路辺数と再計算対象辺数を表示する。**解析を取り消す**を押すと、現在の道路辺を終えた後に停止し、途中結果を保存・確定しない。
- 解析は1フレームあたり最大12 msを目安に、時間予算内で複数の道路辺を連続処理する。進捗表示は0.2秒ごとに更新する。単独の道路辺が12 msを超える場合は、その辺を完了してから次フレームへ譲る。
- 解析中に施策を変更した場合も同じく取消扱いとなる。古い施策の途中結果は新しい施策へ適用しない。

## 局所対象の決め方

施策の変更前後それぞれについて、樹冠または設備平面の外周に、対象時刻の太陽高度から求めた最大影長とサンプル間隔を加えた保守的な範囲を作る。この範囲に交差する道路辺を再Raycastする。

日没後は施策による日陰の追加がないため、既存結果を再利用する。シナリオ全体が入れ替わる操作、または前回結果の時刻・道路集合が一致しない場合は安全側で全範囲再計算にフォールバックする。

## 証跡

完了した結果は `StreamingAssets` ではなく、Playerの書込み可能領域へ `latest.json` として原子的に保存する。

```text
%USERPROFILE%\AppData\LocalLow\<CompanyName>\<ProductName>\EnvironmentCostAnalysis\<areaId>\<scenarioId>\latest.json
```

結果の `provenance` には、次を記録する。

- 施策シナリオIDと施策フィンガープリント
- 都市データパッケージ版と manifest SHA-256
- 座標系、解析中心、対象半径、日時・タイムゾーン、道路サンプル間隔、歩行者高さ
- 遮蔽物Raycast条件（Buildingレイヤー）と地表Raycast条件（Roadレイヤー）
- 全道路数、再計算道路数、全範囲／局所再計算の別、結果フィンガープリント

この保存物はRuntime内での検証・監査用であり、経路サーバーへ直接配備しない。サーバー用bundleへの変換・安全な配備はPost-MVPの #65 で扱う。
